NANG WHITELIST

Free • GitHub Actions • tanpa PAT di HTML
Untuk keamanan, HTML statis tidak menyimpan GitHub token. Setelah halaman GitHub Actions terbuka, pilih NANG Whitelist Update → Run workflow → pilih add/remove → isi UserId → Run.

Workflow memakai GITHUB_TOKEN otomatis dari GitHub, sehingga tidak perlu membuat token pribadi untuk sistem ini.
